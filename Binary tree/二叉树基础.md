## 0. 从零开始：先认识二叉树

### 0.1 什么是树

树用来表示“谁属于谁、谁在谁下面”的层级关系。文件夹目录、家谱都可以用树来理解。这里讨论的是有根树：有一个起点叫根节点，除根以外，每个节点只有一个父节点，沿着孩子往下走不会绕回自己。

~~~text
        A            ← 根节点
       / \
      B   C          ← A 的两个孩子
     / \
    D   E            ← B 的两个孩子
~~~

图中的 A、B、C、D、E 是节点；连接节点的线叫边。线条表示关系，不是节点本身。

### 0.2 做题前先懂这些词

| 名称 | 怎么理解 | 上图中的例子 |
| --- | --- | --- |
| 根节点 root | 整棵树最上面的起点，没有父节点 | A |
| 父节点 parent | 某个节点直接上面相连的节点 | B 的父节点是 A |
| 子节点 / 孩子 child | 某个节点直接下面相连的节点 | B 的孩子是 D、E |
| 兄弟节点 | 父节点相同的节点 | B 和 C；D 和 E |
| 叶子节点 leaf | 没有任何孩子的节点 | C、D、E |
| 非叶子节点 | 至少有一个孩子的节点 | A、B |
| 祖先节点 | 从根走到某节点之前经过的节点 | E 的祖先是 A、B |
| 后代节点 | 从某节点向下能走到的节点 | B 的后代是 D、E |
| 子树 subtree | 某节点和它的全部后代构成的树 | B、D、E 构成以 B 为根的子树 |
| 节点的度 | 该节点直接拥有的孩子数量 | A 的度为 2，C 的度为 0 |
| 路径 | 从一个节点到另一个节点经过的节点序列 | A → B → E |

“子树”必须包含该节点的全部后代，不能随意摘掉一部分。最近公共祖先题通常允许一个节点成为它自己的祖先，具体以题意为准。

### 0.3 什么是二叉树

**二叉树：每个节点最多有两个孩子，并且区分左孩子和右孩子。** 可以没有孩子，也可以只有一个孩子；不要求每个节点都有两个。

~~~text
空树：             单节点：         只有左孩子：       只有右孩子：
None                 A                A                  A
                                     /                    \
                                    B                      B
~~~

“只有左孩子”和“只有右孩子”是不同结构。二叉树的值也不要求有序；普通二叉树不保证左边小、右边大。

~~~python
empty_root = None  # 空树：连根节点都没有
# 单节点树只有根；根的 left、right 都是 None，同时根也是叶子
# None 表示“没有节点”，不是一个值为 0 的节点
# 节点值可以为 0、负数或重复值，是否允许取决于题目
~~~

### 0.4 层数、深度、高度：统一怎么算

本笔记按“节点数”计数：根在第 1 层，空树高度为 0，叶子高度为 1。

~~~text
        A            第 1 层：A 的深度为 1
       / \
      B   C          第 2 层：B、C 的深度为 2
     /
    D                第 3 层：D 的深度为 3
~~~

- **节点深度**：从根走到当前节点，经过多少个节点；从上往下数。
- **节点高度**：从当前节点到它下面最远的叶子，经过多少个节点；由下面往上算。
- **整棵树的最大深度 / 高度**：根到最远叶子的节点数，上图为 3。
- **最小深度**：根到最近叶子的节点数，上图为 2，因为 A → C 已经到叶子。
- 上图 B 的深度为 2、高度为 2；C 的深度为 2、高度为 1。

有些教材按“边数”计数，此时根深度为 0、叶子高度为 0。先看题目约定；LeetCode 104、111 的树深度按节点数计。

~~~python
# 求高度：先得到左右子树高度，再算当前高度，常用后序
# 求某节点深度：从父节点向孩子传 depth + 1，常用前序或 BFS
# 非空树高度 = 1 + max(左子树高度, 右子树高度)
# 非空树最小深度不能直接取两边最小值：空孩子不是叶子
~~~

### 0.5 满二叉树：每一层都填满

你说的“慢二叉树”通常写作“满二叉树”。本笔记沿用 PDF 的定义：**每一层的节点都达到这一层的最大数量，叶子都在同一层。**

~~~text
满二叉树：                  不是满二叉树：
        1                         1
       / \                       / \
      2   3                     2   3
     / \ / \                   / \
    4  5 6  7                 4   5
~~~

左图共 3 层，每层分别有 1、2、4 个节点，共 7 个节点。右图虽然每个非叶子节点都有两个孩子，但叶子不在同一层，因此不是本 PDF 定义的满二叉树。

注意英文术语：本 PDF 的“满二叉树”对应 perfect binary tree；一些英文资料的 full / proper binary tree 仅要求节点有 0 或 2 个孩子。不要把后一个较弱条件单独当作这里的定义。

~~~python
k = 3  # 满二叉树一共有 3 层，根为第 1 层
total_nodes = 2 ** k - 1  # 节点总数：2^3 - 1 = 7
leaf_nodes = 2 ** (k - 1)  # 叶子数：最后一层有 2^(3-1) = 4 个节点
last_layer_nodes = 1 << (k - 1)  # 左移 k-1 位也能计算 2^(k-1)
~~~

用法：当你能证明某棵子树是满二叉树时，就能直接用公式计算节点数，不必逐个遍历。

### 0.6 完全二叉树：最后一层可以不满，但必须靠左

必须同时满足：**最后一层之前全部填满；最后一层从左往右连续排列，中间不能留空位。**

~~~text
完全且满：          完全但不满：          不是完全：
      1                   1                   1
     / \                 / \                 / \
    2   3               2   3               2   3
   / \ / \             / \ /               /   /
  4  5 6  7           4  5 6               4   6
~~~

右图在本来应有“2 的右孩子”的位置出现空位，后面却还有“3 的左孩子”，所以不完全。

~~~text
只有左孩子：是完全二叉树       只有右孩子：不是完全二叉树
        1                              1
       /                                \
      2                                  2
~~~

记法：按层从左往右给所有“孩子位置”排队，**出现第一个空位置后，后面不能再有非空节点**。

~~~python
# 满二叉树一定是完全二叉树
# 完全二叉树不一定是满二叉树，例如上面的 6 节点树
# 完全二叉树除最后一层外都满，不能只看“底部似乎靠左”
# 完全二叉树适合连续数组存储，是二叉堆的结构基础
~~~

题目 222 利用的正是完全二叉树性质。它的“最左链高度等于最右链高度就判满”仅在**已知当前树完全**的前提下成立，不能套到任意二叉树。

### 0.7 二叉搜索树 BST：看的是值的大小关系

**每个节点的整个左子树都比它小，整个右子树都比它大；左右子树也遵守这个规则。** 本节先按没有重复值的严格 BST 讨论。

~~~text
合法 BST：                    非法 BST：
        4                           5
       / \                         / \
      2   7                       3   8
     / \                         / \
    1   3                       2   6
~~~

右图的 6 虽然大于它的父节点 3，却位于 5 的左子树中，违反了“左子树所有值小于 5”。

~~~python
# 查找目标值 3：从 4 开始，3 < 4，所以走左边到 2
# 接着 3 > 2，所以走右边到 3，找到目标
# BST 的中序遍历结果严格递增：上面合法树得到 [1, 2, 3, 4, 7]
# 普通二叉树没有这些数值约束，不能根据大小只搜一边
~~~

BST 不要求完整或平衡。下面也是合法 BST，但搜索最后一个节点需要沿整条链走：

~~~text
1
 \
  2
   \
    3
     \
      4
~~~

### 0.8 平衡二叉树：每个节点的左右高度差都不超过 1

这里使用高度平衡定义：**对树中的每一个节点，它的左右子树高度差的绝对值都不超过 1**。因此，不仅根要平衡，左右子树内部也必须平衡。

~~~text
平衡：                       不平衡：
        1                          1
       / \                        /
      2   3                      2
     /                          /
    4                          3
~~~

左图根的左右高度为 2 和 1，差为 1；右图根的左右高度为 2 和 0，差为 2。

~~~python
left_height = 2  # 假设当前节点的左子树高度为 2
right_height = 1  # 假设当前节点的右子树高度为 1
current_balanced = abs(left_height - right_height) <= 1  # 只检查当前节点这一处
# 整棵树平衡还需要所有子树都平衡，不能只检查根节点
~~~

平衡只限制形状，不限制值。**AVL 树是满足这种高度平衡要求的二叉搜索树**，同时具备“搜索有序”和“高度平衡”两种性质。其他平衡搜索树的定义可能不同，例如红黑树不要求每个节点高度差都不超过 1。

满二叉树一定完全；完全二叉树一定高度平衡；高度平衡的树不一定完全：

~~~text
平衡但不完全：
      1
     / \
    2   3
         \
          4
~~~

### 0.9 斜二叉树、链状树和二叉堆

每个非叶子节点都只有一个孩子时，树会退化成链，高度等于节点数。孩子一直在左边叫左斜树，一直在右边叫右斜树；左右交替仍然可能退化成链。

~~~python
# n 个节点的链：高度为 n，递归栈最坏需要 O(n)
# 高度平衡树：高度为 O(log n)，递归栈通常是 O(log n)
# BST 不自动保持平衡，连续插入递增值容易得到右斜树
~~~

**二叉堆 = 完全二叉树的形状 + 父子之间的大小约束。** 小顶堆父节点不大于孩子，大顶堆父节点不小于孩子；不要求“整个左边小于根、整个右边大于根”，所以堆和 BST 是不同结构。

~~~python
import heapq  # Python 标准库 heapq 默认实现小顶堆
heap = [3, 1, 4]  # 使用列表保存元素
heapq.heapify(heap)  # 原地建小顶堆，时间 O(n)
smallest = heap[0]  # 查看最小值，不删除，时间 O(1)
heapq.heappush(heap, 2)  # 插入元素并维护堆，时间 O(log n)
removed = heapq.heappop(heap)  # 删除并返回最小值，时间 O(log n)
# 堆数组整体不一定有序，它只满足堆的父子关系
# Python 的 dict 和 set 是哈希表，不是 C++ 中有序 map/set 那样的平衡搜索树
~~~

### 0.10 一张表区分这些树

| 类型 | 主要限制 | 值必须有序吗 | 做题时有什么用 |
| --- | --- | --- | --- |
| 普通二叉树 | 每个节点最多两个孩子，区分左右 | 不需要 | 所有二叉树题的基础 |
| 满二叉树 | 每层全部填满 | 不需要 | 用 2^h - 1 计算节点数 |
| 完全二叉树 | 上面填满，最后一层连续靠左 | 不需要 | 数组存储、节点计数、堆 |
| 高度平衡二叉树 | 每个节点左右高度差不超过 1 | 不需要 | 后序求高度并检查差值 |
| BST | 左子树所有值小于根，右子树所有值大于根 | 需要 | 按大小搜索、中序得到有序序列 |
| AVL | 既是 BST，又高度平衡 | 需要 | 通过旋转维护平衡，基础题只需先掌握定义 |
| 二叉堆 | 完全二叉树，父子满足堆序 | 仅父子约束 | 优先队列、取最小或最大值 |

这些类别可以重叠。例如一棵树可以同时是满二叉树、完全二叉树、高度平衡树和 BST；形状与数值是两条不同的判断线。

### 0.11 常见公式与使用前提

~~~python
i = 3  # 当前层数，根为第 1 层
max_nodes_at_layer = 2 ** (i - 1)  # 任意二叉树第 i 层至多有这么多节点
h = 3  # 树一共有 h 层，按非空树讨论
max_nodes_total = 2 ** h - 1  # 任意高度 h 的二叉树至多有这么多节点
min_nodes_total = h  # 同样高度至少需要 h 个节点，一条链即可
min_complete_nodes = 2 ** (h - 1)  # 高度 h 的完全二叉树至少有这么多节点
n = 6  # 非空完全二叉树的节点数
complete_height = n.bit_length()  # 等价于 floor(log2(n)) + 1，这里等于 3
edges = n - 1  # 任意 n 节点非空树都有 n-1 条边
# 对任意非空二叉树：叶子数 n0 = 有两个孩子的节点数 n2 + 1
# ** 是乘方；^ 是按位异或，在 Python 中 2^h 不是 2 的 h 次方
~~~

## 1. Python 节点定义、复杂度和存储

### 1.1 二叉树节点定义

~~~python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):  # 创建一个树节点
        self.val = val  # 保存节点值
        self.left = left  # 指向左子节点，没有则为 None
        self.right = right  # 指向右子节点，没有则为 None
~~~

### 1.2 常用导入

~~~python
from collections import deque  # deque 适合做双端队列和 BFS 队列
from typing import Optional, List  # 类型标注，可按平台需要删除
~~~

### 1.3 复杂度记忆

- 链式二叉树遍历：时间 O(n)。
- 递归 DFS 额外空间：O(h)，退化成链时是 O(n)。
- 迭代 DFS 栈空间：O(h)；层序 BFS 队列空间：O(w)，w 是最大宽度。
- 不要使用列表 pop(0) 做队列，它是 O(n)；BFS 使用 deque.popleft()。
- BST 查找、插入、删除平均 O(log n)，退化时 O(n)，不能默认一定平衡。

### 1.4 顺序存储下标

~~~python
left_index = 2 * i + 1  # 下标 i 节点的左孩子
right_index = 2 * i + 2  # 下标 i 节点的右孩子
parent_index = (i - 1) // 2  # i > 0 时，节点 i 的父节点
~~~

链式节点更适合大多数二叉树题；堆、优先队列经常直接使用数组。

## 2. 栈、队列和递归模板

### 2.1 栈：后进先出

~~~python
stack = []  # 用列表表示栈
stack.append(x)  # 从栈顶压入元素
top = stack[-1]  # 查看栈顶但不删除
value = stack.pop()  # 删除并返回栈顶元素
is_empty = not stack  # 判断栈是否为空
~~~

### 2.2 队列：先进先出

~~~python
q = deque()  # 创建双端队列
q.append(x)  # 从队尾入队
x = q.popleft()  # 从队头出队，复杂度 O(1)
front = q[0]  # 查看队头但不删除
back = q[-1]  # 查看队尾但不删除
~~~

### 2.3 递归三要素

1. 确定函数参数和返回值：当前节点需要什么信息，子问题返回什么结果。
2. 确定终止条件：通常是 node is None；最小深度、路径和还要考虑叶子。
3. 确定单层逻辑：根据前序、中序或后序安排当前节点操作。

~~~python
def dfs(node):  # 定义处理当前节点的递归函数
    if node is None:  # 空节点是最常见的终止条件
        return  # 结束当前递归分支
    dfs(node.left)  # 递归处理左子树
    dfs(node.right)  # 递归处理右子树
~~~

### 2.4 二叉树题中常用的 Python 3 写法

~~~python
if node is None:  # 用 is 判断 None，不要写成 node == None
    pass  # 在函数中通常写 return，这里用 pass 保持示例可独立编译
left, right = node.right, node.left  # 元组赋值可以一次交换左右引用
path_copy = path.copy()  # 保存回溯路径的独立副本
def outer():  # 示例：外层函数提供被修改的变量
    total = 0  # 定义外层变量
    def update():  # 定义嵌套函数
        nonlocal total  # 在嵌套函数中修改外层变量
index = {value: i for i, value in enumerate(values)}  # 快速建立值到下标的映射
for _ in range(len(q)):  # 下划线表示循环变量本身不使用
    node = q.popleft()  # deque 队头删除为 O(1)
minimum = float("inf")  # 正无穷，适合初始化最小值
maximum = float("-inf")  # 负无穷，适合初始化最大值
~~~

## 3. 深度优先遍历：递归法

### 3.1 前序遍历（144）

~~~python
def preorderTraversal(root: Optional[TreeNode]) -> List[int]:  # 返回中左右结果
    result = []  # 保存遍历结果
    def dfs(node):  # 定义递归函数
        if node is None:  # 空节点不访问
            return  # 结束当前分支
        result.append(node.val)  # 前序：先访问中节点
        dfs(node.left)  # 再访问左子树
        dfs(node.right)  # 最后访问右子树
    dfs(root)  # 从根节点开始
    return result  # 返回结果数组
~~~

### 3.2 中序遍历（94）

~~~python
def inorderTraversal(root: Optional[TreeNode]) -> List[int]:  # 返回左中右结果
    result = []  # 保存遍历结果
    def dfs(node):  # 定义递归函数
        if node is None:  # 空节点不访问
            return  # 结束当前分支
        dfs(node.left)  # 先访问左子树
        result.append(node.val)  # 再访问中节点
        dfs(node.right)  # 最后访问右子树
    dfs(root)  # 从根节点开始
    return result  # 返回结果数组
~~~

## 4. 深度优先遍历：迭代法

### 4.1 前序：中左右

~~~python
def preorderTraversal(root: Optional[TreeNode]) -> List[int]:  # 迭代实现前序
    if root is None:  # 空树没有结果
        return []  # 返回空列表
    result = []  # 保存访问顺序
    stack = [root]  # 根节点先入栈
    while stack:  # 栈不空就继续
        node = stack.pop()  # 取出当前要访问的节点
        result.append(node.val)  # 先访问中节点
        if node.right is not None:  # 右子树存在才入栈
            stack.append(node.right)  # 右子树先入栈
        if node.left is not None:  # 左子树存在才入栈
            stack.append(node.left)  # 左子树后入栈，从而先出栈
    return result  # 返回中左右结果
~~~

### 4.2 中序：左中右

~~~python
def inorderTraversal(root: Optional[TreeNode]) -> List[int]:  # 迭代实现中序
    result = []  # 保存遍历结果
    stack = []  # 保存沿左链向下的节点
    cur = root  # cur 指向当前扫描位置
    while cur is not None or stack:  # 还有节点或栈中还有回溯节点
        while cur is not None:  # 一直向左走
            stack.append(cur)  # 把当前节点压栈
            cur = cur.left  # 移动到左孩子
        cur = stack.pop()  # 左边到底后取出最近的根节点
        result.append(cur.val)  # 访问中节点
        cur = cur.right  # 转向右子树
    return result  # 返回左中右结果
~~~

### 4.3 后序：左右中

~~~python
def postorderTraversal(root: Optional[TreeNode]) -> List[int]:  # 迭代实现后序
    if root is None:  # 空树没有结果
        return []  # 返回空列表
    result = []  # 暂存中右左顺序
    stack = [root]  # 根节点入栈
    while stack:  # 栈不空继续
        node = stack.pop()  # 取出当前节点
        result.append(node.val)  # 先记录中节点
        if node.left is not None:  # 左节点存在才入栈
            stack.append(node.left)  # 左节点先入栈
        if node.right is not None:  # 右节点存在才入栈
            stack.append(node.right)  # 右节点后入栈，从而先处理右节点
    result.reverse()  # 中右左反转为左右中
    return result  # 返回后序结果
~~~

### 4.4 统一迭代法：空标记法

中序模板如下；只需调整节点和 None 标记的压栈顺序，就能得到前序和后序。

~~~python
def inorderTraversal(root: Optional[TreeNode]) -> List[int]:  # 统一模板实现中序
    result = []  # 保存结果
    stack = []  # 栈中可放节点或 None 标记
    if root is not None:  # 非空树才初始化
        stack.append(root)  # 根节点入栈
    while stack:  # 栈不空继续
        node = stack.pop()  # 取出栈顶
        if node is None:  # None 表示下一个节点应该访问
            result.append(stack.pop().val)  # 取出真正节点并访问
            continue  # 本轮结束
        if node.right is not None:  # 右子树最后处理
            stack.append(node.right)  # 右子树先压栈
        stack.append(node)  # 重新压入当前节点
        stack.append(None)  # None 标记当前节点的访问时机
        if node.left is not None:  # 左子树最先处理
            stack.append(node.left)  # 左子树最后压栈，从而先出栈
    return result  # 返回左中右结果
~~~

调整规则：前序把访问标记放在左右子树之前；中序放在左子树之后、右子树之前；后序放在左右子树之后。

def isSymmetric(root: Optional[TreeNode]) -> bool:  # 判断是否轴对称
    def mirror(left, right):  # 判断两个节点是否互为镜像
        if left is None and right is None:  # 两边都空

### 7.2 最小深度（111）

最小深度必须到达叶子，不能把只有一边为空的节点当作结束。

~~~python
def minDepth(root: Optional[TreeNode]) -> int:  # 求根到最近叶子的路径长度
    if root is None:  # 空树深度为 0
        return 0  # 返回 0
    if root.left is None and root.right is None:  # 当前节点是叶子
        return 1  # 叶子层深度为 1
    if root.left is None:  # 左子树为空，只能走右边
        return 1 + minDepth(root.right)  # 不能把空左子树计入最小值
    if root.right is None:  # 右子树为空，只能走左边
        return 1 + minDepth(root.left)  # 不能把空右子树计入最小值
    return 1 + min(minDepth(root.left), minDepth(root.right))  # 两边都有时取较小深度
~~~

BFS 版本第一次遇到叶子即可返回：

### 7.3 完全二叉树节点个数（222）

若左右高度相同则当前树是满二叉树，否则递归左右子树。

~~~python
def countNodes(root: Optional[TreeNode]) -> int:  # 统计完全二叉树节点数
    if root is None:  # 空树节点数为 0
        return 0  # 返回 0
    left = root  # 用于计算左侧高度
    right = root  # 用于计算右侧高度
    left_height = 0  # 左边高度初始值
    right_height = 0  # 右边高度初始值
    while left is not None:  # 沿左链向下
        left_height += 1  # 高度加一
        left = left.left  # 继续向左
    while right is not None:  # 沿右链向下
        right_height += 1  # 高度加一
        right = right.right  # 继续向右
    if left_height == right_height:  # 左右高度相等说明当前是满二叉树
        return (1 << left_height) - 1  # 满树节点数为 2^h - 1
    return 1 + countNodes(root.left) + countNodes(root.right)  # 否则递归左右子树
~~~

### 7.4 平衡二叉树（110）

~~~python
def isBalanced(root: Optional[TreeNode]) -> bool:  # 判断是否高度平衡
    def height(node):  # 返回高度或 -1
        if node is None:  # 空树高度为 0
            return 0  # 返回高度 0
        left_height = height(node.left)  # 求左子树高度
        if left_height == -1:  # 左子树已经不平衡
            return -1  # 向上层传递失败标记
        right_height = height(node.right)  # 求右子树高度
        if right_height == -1:  # 右子树已经不平衡
            return -1  # 向上层传递失败标记
        if abs(left_height - right_height) > 1:  # 当前高度差超过 1
            return -1  # 当前树不平衡
        return 1 + max(left_height, right_height)  # 返回当前树高度
    return height(root) != -1  # 高度不是 -1 就表示整棵树平衡
~~~

            result.append(path.copy())  # 复制路径，避免回溯修改结果
        dfs(node.left, remain, path)  # 搜索左子树
        dfs(node.right, remain, path)  # 搜索右子树
        path.pop()  # 回溯撤销当前节点
    dfs(root, targetSum, [])  # 从根节点开始
    return result  # 返回所有路径
~~~

## 9. 根据遍历序列构造二叉树

### 9.1 中序 + 后序构造（106）

后序最后一个元素是根；在中序中找到根后，左边是左子树，右边是右子树。

~~~python
def buildTree(inorder: List[int], postorder: List[int]) -> Optional[TreeNode]:  # 根据中序后序建树
    if not inorder or not postorder:  # 任一序列为空表示没有节点
        return None  # 返回空树
    index = {value: i for i, value in enumerate(inorder)}  # 记录中序下标
    def build(in_left, in_right, post_left, post_right):  # 使用区间构造子树
        if in_left > in_right:  # 区间为空
            return None  # 没有节点
        root_value = postorder[post_right]  # 后序最后一个是根
        root = TreeNode(root_value)  # 创建根节点
        root_index = index[root_value]  # 找到根在中序的位置
        left_size = root_index - in_left  # 计算左子树节点数
        root.left = build(in_left, root_index - 1, post_left, post_left + left_size - 1)  # 构造左子树
        root.right = build(root_index + 1, in_right, post_left + left_size, post_right - 1)  # 构造右子树
        return root  # 返回当前子树根
    return build(0, len(inorder) - 1, 0, len(postorder) - 1)  # 构造整棵树
~~~

### 9.2 前序 + 中序构造（105）

~~~python
def buildTree(preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:  # 根据前序中序建树
    if not preorder or not inorder:  # 任一序列为空表示没有节点
        return None  # 返回空树
    index = {value: i for i, value in enumerate(inorder)}  # 记录中序下标
    def build(pre_left, pre_right, in_left, in_right):  # 使用两个序列区间构造
        if pre_left > pre_right:  # 区间为空
            return None  # 没有节点
        root_value = preorder[pre_left]  # 前序第一个是根
        root = TreeNode(root_value)  # 创建根节点
        root_index = index[root_value]  # 找到根在中序的位置
        left_size = root_index - in_left  # 计算左子树大小
        root.left = build(pre_left + 1, pre_left + left_size, in_left, root_index - 1)  # 构造左子树
        root.right = build(pre_left + left_size + 1, pre_right, root_index + 1, in_right)  # 构造右子树
        return root  # 返回当前根
    return build(0, len(preorder) - 1, 0, len(inorder) - 1)  # 构造整棵树
~~~

前序 + 后序通常不能唯一确定普通二叉树；前序 + 中序、后序 + 中序在节点值不重复时可以唯一确定。

### 9.3 最大二叉树（654）

~~~python
def constructMaximumBinaryTree(nums: List[int]) -> Optional[TreeNode]:  # 根据数组构造最大二叉树
    if not nums:  # 数组为空时没有节点
        return None  # 返回空树
    max_index = max(range(len(nums)), key=nums.__getitem__)  # 找到最大值下标
    root = TreeNode(nums[max_index])  # 最大值作为根节点
    root.left = constructMaximumBinaryTree(nums[:max_index])  # 左侧构造左子树
    root.right = constructMaximumBinaryTree(nums[max_index + 1:])  # 右侧构造右子树
    return root  # 返回根节点
~~~

切片会复制数组，最坏复杂度可能 O(n²)；需要优化时用下标边界或单调栈构造 O(n) 解法。

## 10. 合并二叉树（617）

~~~python
def mergeTrees(root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:  # 合并两棵树
    if root1 is None:  # 第一棵树当前位置为空
        return root2  # 返回第二棵树当前位置
    if root2 is None:  # 第二棵树当前位置为空
        return root1  # 返回第一棵树当前位置
    root1.val += root2.val  # 当前节点值相加
    root1.left = mergeTrees(root1.left, root2.left)  # 合并左子树
    root1.right = mergeTrees(root1.right, root2.right)  # 合并右子树
    return root1  # 返回合并结果，复用 root1
~~~

若不能修改原树，应创建新节点，而不是复用 root1。

## 11. 普通二叉树的最近公共祖先（236）

后序回溯：当前节点是 p 或 q 时直接返回；左右子树都找到时当前节点就是答案；只有一边找到时把结果向上返回。

~~~python
def lowestCommonAncestor(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:  # 求普通二叉树 LCA
    if root is None or root is p or root is q:  # 空节点或命中目标节点
        return root  # 把结果向上返回
    left = lowestCommonAncestor(root.left, p, q)  # 在左子树搜索
    right = lowestCommonAncestor(root.right, p, q)  # 在右子树搜索
    if left is not None and right is not None:  # 两边各找到一个目标
        return root  # 当前节点是最近公共祖先
    if left is not None:  # 只有左边找到
        return left  # 把左边结果继续向上返回
    return right  # 右边找到或两边都没找到
~~~

若题目不保证 p、q 一定存在，需要额外统计目标数量，否则只找到一个节点也可能被误判为公共祖先。

## 12. 二叉搜索树 BST 专题

### 12.1 BST 搜索（700）

~~~python
def searchBST(root: Optional[TreeNode], val: int) -> Optional[TreeNode]:  # 在 BST 中搜索值
    if root is None:  # 搜索到空位置
        return None  # 没有找到
    if root.val == val:  # 当前值就是目标
        return root  # 返回当前节点
    if val < root.val:  # 目标值更小
        return searchBST(root.left, val)  # 只搜索左子树
    return searchBST(root.right, val)  # 目标值更大，只搜索右子树
~~~

迭代写法：

~~~python
def searchBSTIter(root: Optional[TreeNode], val: int) -> Optional[TreeNode]:  # 迭代搜索 BST
    cur = root  # 从根节点开始
    while cur is not None:  # 当前节点不为空就继续
        if cur.val == val:  # 找到目标值
            return cur  # 返回节点
        if val < cur.val:  # 目标更小
            cur = cur.left  # 向左走
        else:  # 目标更大
            cur = cur.right  # 向右走
    return None  # 搜索失败
~~~

### 12.2 验证 BST（98）

不能只比较当前节点和左右孩子；必须保证整个左子树小于根、整个右子树大于根。中序遍历应该严格递增。

~~~python
def isValidBST(root: Optional[TreeNode]) -> bool:  # 中序验证 BST
    stack = []  # 保存回溯节点
    cur = root  # 从根开始
    previous = None  # 保存中序前一个值
    while cur is not None or stack:  # 还有节点未访问
        while cur is not None:  # 向左走到底
            stack.append(cur)  # 保存路径节点
            cur = cur.left  # 继续左移
        cur = stack.pop()  # 取出中序下一个节点
        if previous is not None and cur.val <= previous:  # 中序不是严格递增
            return False  # 不是有效 BST
        previous = cur.val  # 更新前一个值
        cur = cur.right  # 转向右子树
    return True  # 所有中序值严格递增
~~~

上下界写法：

~~~python
def isValidBSTByRange(root: Optional[TreeNode]) -> bool:  # 上下界验证 BST
    def check(node, low, high):  # node 必须位于开区间
        if node is None:  # 空树满足约束
            return True  # 返回真
        if not (low < node.val < high):  # 当前值越界
            return False  # 不符合 BST
        return check(node.left, low, node.val) and check(node.right, node.val, high)  # 收紧边界
    return check(root, float("-inf"), float("inf"))  # 初始没有有限边界
~~~

### 12.3 BST 最小绝对差（530）

~~~python
def getMinimumDifference(root: Optional[TreeNode]) -> int:  # 求 BST 最小绝对差
    stack = []  # 中序遍历栈
    cur = root  # 当前节点
    previous = None  # 前一个中序值
    answer = float("inf")  # 初始化最小差值
    while cur is not None or stack:  # 遍历所有节点
        while cur is not None:  # 向左走到底
            stack.append(cur)  # 节点入栈
            cur = cur.left  # 继续左走
        cur = stack.pop()  # 取出中序节点
        if previous is not None:  # 已经有前一个节点
            answer = min(answer, cur.val - previous)  # 更新相邻差值
        previous = cur.val  # 保存当前值
        cur = cur.right  # 转向右子树
    return answer  # 返回最小绝对差
~~~

### 12.4 BST 众数（501）

~~~python
def findMode(root: Optional[TreeNode]) -> List[int]:  # 找 BST 所有众数
    stack = []  # 中序遍历栈
    cur = root  # 当前节点
    previous = None  # 前一个值
    current_count = 0  # 当前值连续出现次数
    max_count = 0  # 最大频次
    result = []  # 众数列表
    while cur is not None or stack:  # 遍历中序序列
        while cur is not None:  # 向左走到底
            stack.append(cur)  # 入栈
            cur = cur.left  # 左移
        cur = stack.pop()  # 取出节点
        if cur.val == previous:  # 和前一个值相同
            current_count += 1  # 连续频次加一
        else:  # 遇到新值
            current_count = 1  # 从一次开始计数
            previous = cur.val  # 更新当前值
        if current_count > max_count:  # 出现更高频次
            max_count = current_count  # 更新最大频次
            result = [cur.val]  # 清空旧答案
        elif current_count == max_count:  # 频次相同
            result.append(cur.val)  # 追加当前众数
        cur = cur.right  # 转向右子树
    return result  # 返回众数列表
~~~

### 12.5 BST 最近公共祖先（235）

~~~python
def lowestCommonAncestorBST(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:  # 求 BST 的 LCA
    cur = root  # 从根开始
    while cur is not None:  # 当前节点不为空
        if p.val < cur.val and q.val < cur.val:  # 两个目标都在左边
            cur = cur.left  # 向左搜索
        elif p.val > cur.val and q.val > cur.val:  # 两个目标都在右边
            cur = cur.right  # 向右搜索
        else:  # 一左一右或当前就是其中一个
            return cur  # 当前节点就是最近公共祖先
    return None  # 题目保证目标存在时不会到这里
~~~

### 12.6 BST 插入（701）

~~~python
def insertIntoBST(root: Optional[TreeNode], val: int) -> TreeNode:  # 向 BST 插入新值
    if root is None:  # 找到空位置
        return TreeNode(val)  # 创建并返回新节点
    if val < root.val:  # 新值更小
        root.left = insertIntoBST(root.left, val)  # 插入左子树
    elif val > root.val:  # 新值更大
        root.right = insertIntoBST(root.right, val)  # 插入右子树
    return root  # 返回当前根节点
~~~

### 12.7 删除 BST 节点（450）

~~~python
def deleteNode(root: Optional[TreeNode], key: int) -> Optional[TreeNode]:  # 删除 BST 中的 key
    if root is None:  # 没有找到目标
        return None  # 返回空
    if key < root.val:  # 目标在左子树
        root.left = deleteNode(root.left, key)  # 递归删除左边
        return root  # 当前根保持不变
    if key > root.val:  # 目标在右子树
        root.right = deleteNode(root.right, key)  # 递归删除右边
        return root  # 当前根保持不变
    if root.left is None:  # 当前节点没有左孩子
        return root.right  # 用右孩子替代当前节点
    if root.right is None:  # 当前节点没有右孩子
        return root.left  # 用左孩子替代当前节点
    successor = root.right  # 从右子树寻找后继
    while successor.left is not None:  # 后继是右子树最左节点
        successor = successor.left  # 向左寻找
    root.val = successor.val  # 用后继值覆盖当前值
    root.right = deleteNode(root.right, successor.val)  # 删除右子树中的后继
    return root  # 返回调整后的根节点
~~~

### 12.8 修剪 BST（669）

~~~python
def trimBST(root: Optional[TreeNode], low: int, high: int) -> Optional[TreeNode]:  # 保留 [low, high] 范围
    if root is None:  # 空节点直接返回
        return None  # 没有节点可保留
    if root.val < low:  # 当前值太小
        return trimBST(root.right, low, high)  # 左子树更小，整棵舍弃
    if root.val > high:  # 当前值太大
        return trimBST(root.left, low, high)  # 右子树更大，整棵舍弃
    root.left = trimBST(root.left, low, high)  # 修剪左子树
    root.right = trimBST(root.right, low, high)  # 修剪右子树
    return root  # 返回保留下来的当前节点
~~~

### 12.9 有序数组转平衡 BST（108）

~~~python
def sortedArrayToBST(nums: List[int]) -> Optional[TreeNode]:  # 有序数组转平衡 BST
    def build(left, right):  # 构造闭区间 [left, right]
        if left > right:  # 区间为空
            return None  # 返回空节点
        mid = (left + right) // 2  # 取中间位置
        root = TreeNode(nums[mid])  # 中间值作为根
        root.left = build(left, mid - 1)  # 左半区构造左子树
        root.right = build(mid + 1, right)  # 右半区构造右子树
        return root  # 返回当前根
    return build(0, len(nums) - 1)  # 构造整棵树
~~~

### 12.10 BST 转累加树（538、1038）

~~~python
def convertBST(root: Optional[TreeNode]) -> Optional[TreeNode]:  # 转为大于等于当前值的累加树
    total = 0  # 保存右侧已访问节点的累加和
    def dfs(node):  # 反向中序遍历
        nonlocal total  # 允许修改外层 total
        if node is None:  # 空节点结束
            return  # 返回上一层
        dfs(node.right)  # 先访问更大的右子树
        total += node.val  # 把当前值加入累加和
        node.val = total  # 当前节点改为累加值
        dfs(node.left)  # 最后访问更小的左子树
    dfs(root)  # 从根节点开始
    return root  # 返回修改后的树
~~~

## 13. 题型选择速查

| 题目特征 | 优先方法 | 关键判断 |
| --- | --- | --- |
| 输出中左右、左中右、左右中 | DFS 递归或栈 | 根节点访问位置 |
| 一层一层处理、每层统计 | BFS + deque | 用 len(q) 固定层边界 |
| 反转、交换左右 | 递归或栈 | 交换 left、right |
| 对称 | 双指针递归 | 外侧对外侧、内侧对内侧 |
| 最大深度 | 后序返回高度 | 1 + max(left, right) |
| 最小深度 | BFS 或后序 | 必须到叶子 |
| 平衡 | 后序返回高度 | -1 作为不平衡标记 |
| 所有根叶路径 | 前序 + 回溯 | 结果保存路径副本 |
| 根叶路径和 | 目标值递减 | 叶子处判断剩余值 |
| 根据遍历建树 | 根分割中序 | 映射下标，边界递归 |
| 普通树 LCA | 后序回溯 | 左右都找到时当前为答案 |
| BST 查找、插入 | 比较大小 | 每次只走一边 |
| BST 合法性 | 中序递增或上下界 | 不能只看父子 |
| BST 最小差、众数 | 中序序列 | 利用有序性 |
| BST 删除 | 分类讨论 | 两孩子用后继或前驱 |
| BST 累加树 | 反向中序 | 右中左并维护累计和 |

## 14. 高频易错点清单

1. root is None 和“当前节点是叶子”不是一回事；最小深度、路径和必须单独判断叶子。
2. 层序遍历必须先保存 len(q)，否则新入队节点会被算进当前层。
3. 队列使用 deque.popleft()，不要使用 list.pop(0)。
4. 前序迭代入栈顺序是右后左；否则顺序会变成左右中。
5. 中序迭代的核心是“沿左链入栈，弹出访问，再转右”。
6. 回溯路径要在递归返回前撤销；结果列表要保存副本。
7. BST 验证不能只检查 left.val < root.val < right.val，要约束整个子树。
8. BST 中序是严格递增还是非递减，取决于题目是否允许重复值。
9. 删除 BST 的两个孩子场景不能直接丢掉一棵子树，要用前驱或后继保持有序。
10. 普通树 LCA 靠后序回溯；BST LCA 靠大小关系。
11. 递归深度可能超过 Python 默认限制；极端退化树可改迭代。
12. 修改树的题目先确认是否允许原地修改；不允许时要新建节点。
13. 构造树时若节点值重复，值到下标字典不适用，需要题目额外保证或改用位置列表。
14. 极值可用 float("inf") 和 float("-inf") 初始化；也可以用 None 表示未初始化。

## 15. 刷题时的最短思考流程

1. 判断是普通二叉树、完全二叉树还是 BST。
2. 判断需要 DFS 还是 BFS：路径和子树关系通常 DFS，按层统计通常 BFS。
3. 若是 DFS，确定当前节点操作位于左递归前、左右递归之间，还是右递归后。
4. 明确递归返回值：高度、布尔值、节点、路径数量，还是通过外部变量收集答案。
5. 写出空节点和叶子节点边界，再写普通节点逻辑。
6. 涉及路径就考虑回溯；涉及 BST 就考虑中序有序性或大小剪枝。
7. 检查空树、单节点、只有左子树、只有右子树、退化链和重复值边界。
