## 31. 打家劫舍 III

对应原 PDF 第 130-136 页。


原文递归示例的栈空间统一写成 O(log n)，只适用于平衡树。这里用树高 h 表达；记忆化版本还要计入 O(n) 缓存。暴力版存在大量重复计算，最坏为指数级。Python 递归还受解释器递归深度限制，极深链状树可能需要迭代后序遍历。


### 31.1 版本一：暴力递归

原代码 / 片段：PDF 第 132 页。

偷当前节点时，跳过两个孩子，改为考虑孙子；不偷时，直接考虑两个孩子。

```python
class Solution:
    def rob(self, root: "TreeNode | None") -> int:
        if root is None:
            return 0
        if root.left is None and root.right is None:
            return root.val

        # 方案一：偷当前节点，不能偷左右孩子，但可以考虑孙子。
        steal = root.val
        if root.left is not None:
            steal += self.rob(root.left.left) + self.rob(root.left.right)
        if root.right is not None:
            steal += self.rob(root.right.left) + self.rob(root.right.right)

        # 方案二：不偷当前节点，左右孩子分别求最优解。
        skip = self.rob(root.left) + self.rob(root.right)
        return max(steal, skip)
```

时间：最坏为指数级；空间：O(h)，h 为树高。此版本仅用于理解，可能超时。


### 31.2 版本二：记忆化递归

原代码 / 片段：PDF 第 132-133 页。

把每棵子树的答案缓存起来。按键是否存在判断缓存命中，金额为 0 的结果也能复用。

```python
class Solution:
    def rob(self, root: "TreeNode | None") -> int:
        # 每次调用 rob 都创建独立缓存，避免不同调用相互影响。
        memo = {}

        def dfs(node):
            if node is None:
                return 0
            # 用对象身份作键，不要求节点类可哈希。
            key = id(node)
            if key in memo:
                return memo[key]

            steal = node.val
            if node.left is not None:
                steal += dfs(node.left.left) + dfs(node.left.right)
            if node.right is not None:
                steal += dfs(node.right.left) + dfs(node.right.right)

            skip = dfs(node.left) + dfs(node.right)
            memo[key] = max(steal, skip)
            return memo[key]

        return dfs(root)
```

时间：O(n)；空间：O(n)，包括缓存和递归栈。


### 31.3 版本三：树形动态规划（推荐）

原代码 / 片段：PDF 第 133-136 页。

每个节点返回 (不偷该节点的最大金额, 偷该节点的最大金额)。先计算左右孩子，再计算父节点，即后序遍历。

```python
class Solution:
    def rob(self, root: "TreeNode | None") -> int:
        def rob_tree(node):
            if node is None:
                return (0, 0)

            # 左、右、根：父节点的决策依赖孩子的两种状态。
            left = rob_tree(node.left)
            right = rob_tree(node.right)

            # 偷当前节点，左右孩子都必须不偷。
            steal = node.val + left[0] + right[0]
            # 不偷当前节点，每个孩子都可以独立选择偷或不偷。
            skip = max(left) + max(right)
            return (skip, steal)

        return max(rob_tree(root))
```

时间：O(n)；空间：O(h)，平衡树为 O(log n)，链状树为 O(n)。

## 32. 买卖股票的最佳时机

对应原 PDF 第 136-140 页。


### 32.1 版本一：暴力枚举买卖日期

原代码 / 片段：PDF 第 137 页。

买入日期 i 固定后，只枚举之后的卖出日期 j，保证先买后卖。

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        result = 0  # 不交易也是合法选择，收益至少为 0。
        for i in range(len(prices)):
            for j in range(i + 1, len(prices)):
                result = max(result, prices[j] - prices[i])
        return result
```

时间：O(n²)；空间：O(1)。此版本可能超时。


### 32.2 版本二：贪心维护历史最低价

原代码 / 片段：PDF 第 137 页。

把今天视为卖出日，用今天之前（含今天）的最低价计算利润。

```python

    def maxProfit(self, prices: list[int]) -> int:
        low = float("inf")
        result = 0
        for price in prices:
            low = min(low, price)  # 到今天为止能找到的最低买入价。
            result = max(result, price - low)
        return result
```

时间：O(n)；空间：O(1)。


### 32.3 版本三：二维动态规划（原文 DP 版本一）

原代码 / 片段：PDF 第 138-140 页。

dp[i][0] 为第 i 天结束时持股的最多现金，dp[i][1] 为不持股的最多现金。只能买卖一次，买入时直接用 -prices[i]。

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices:
            return 0
        n = len(prices)
        # 用列表推导式逐行创建，避免多行共享同一个列表。
        dp = [[0, 0] for _ in range(n)]
        dp[0][0] = -prices[0]  # 第一天持股，说明当天买入。

        for i in range(1, n):
            # 继续持有，或在今天进行唯一一次买入。
            dp[i][0] = max(dp[i - 1][0], -prices[i])
            # 继续不持股，或卖掉昨天持有的股票。
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] + prices[i])
        return dp[-1][1]
```

时间：O(n)；空间：O(n)。


### 32.4 版本四：两行滚动数组（原文 DP 版本二）

原代码 / 片段：PDF 第 140 页。

每一天只依赖前一天，所以只保留两行。cur 和 prev 始终指向不同的行。

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices:
            return 0
        dp = [[0, 0] for _ in range(2)]
        dp[0][0] = -prices[0]
        for i in range(1, len(prices)):
            # 两行交替复用，所有转移仍从前一天读取。
            cur, prev = i % 2, (i - 1) % 2
            dp[cur][0] = max(dp[prev][0], -prices[i])
            dp[cur][1] = max(dp[prev][1], dp[prev][0] + prices[i])
        return dp[(len(prices) - 1) % 2][1]
```

时间：O(n)；空间：O(1)。

## 33. 本周小结！（动态规划系列六）

### 33.1 周一代码片段：线性打家劫舍的初始化和递推

原代码 / 片段：PDF 第 141 页。

原文在本节回顾了第 29 节的初始化和公式；这里补成可运行的函数。dp[i] 表示前 i+1 间房屋的最大收益。

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        if not nums:
            return 0
        if len(nums) == 1:
            return nums[0]
        dp = [0] * len(nums)
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])
        for i in range(2, len(nums)):
            # 偷第 i 间要跳过 i-1；不偷则沿用 dp[i-1]。
            dp[i] = max(dp[i - 2] + nums[i], dp[i - 1])
        return dp[-1]
```

时间：O(n)；空间：O(n)。

## 35. 买卖股票的最佳时机 III

对应原 PDF 第 150-155 页。


本题为至多两次交易，状态中的“第二次卖出”包含不足两次交易的最优结果。原地更新版本只用于本题条件，不能直接套到有冷冻期的题目。


### 35.1 版本一：五状态二维动态规划

原代码 / 片段：PDF 第 151-154 页。

状态 0：无操作；1：第一次持股；2：第一次交易后不持股；3：第二次持股；4：第二次交易后不持股。交易次数是“至多”，允许用零收益操作理解初始化。

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices:
            return 0
        dp = [[0] * 5 for _ in prices]
        # 第二次持股初始化为 -price，兼容第一次交易收益为 0 的情况。
        dp[0][1] = dp[0][3] = -prices[0]
        for i in range(1, len(prices)):
            dp[i][0] = dp[i - 1][0]
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - prices[i])
            dp[i][2] = max(dp[i - 1][2], dp[i - 1][1] + prices[i])
            dp[i][3] = max(dp[i - 1][3], dp[i - 1][2] - prices[i])
            dp[i][4] = max(dp[i - 1][4], dp[i - 1][3] + prices[i])
        return dp[-1][4]
```

时间：O(n)；空间：O(n)，每行固定 5 个状态。


### 35.2 版本二：一维五状态原地更新

## 36. 买卖股票的最佳时机 IV

对应原 PDF 第 155-159 页。


### 36.1 至多 k 次交易：2k+1 个状态

原代码 / 片段：PDF 第 156-159 页。

0 为无操作，奇数状态为持股，正偶数状态为完成对应交易后不持股。j 每次加 2，同时计算一次买入和卖出。

```python
class Solution:
    def maxProfit(self, k: int, prices: list[int]) -> int:
        if not prices or k <= 0:
            return 0
        dp = [[0] * (2 * k + 1) for _ in prices]
        for j in range(1, 2 * k, 2):
            dp[0][j] = -prices[0]  # 所有持股状态按首日买入初始化。

        for i in range(1, len(prices)):
            for j in range(0, 2 * k - 1, 2):
                # j 是上一次卖出后的状态；j+1 买入，j+2 卖出。
                dp[i][j + 1] = max(dp[i - 1][j + 1],
                                   dp[i - 1][j] - prices[i])
                dp[i][j + 2] = max(dp[i - 1][j + 2],
                                   dp[i - 1][j + 1] + prices[i])
        return dp[-1][2 * k]
```

时间：O(n(k+1))，k≥1 时通常写作 O(nk)；空间：O(n(k+1))。

## 37. 最佳买卖股票时机含冷冻期

### 37.1 四状态动态规划

原代码 / 片段：PDF 第 159-163 页。

0：持股；1：已过冷冻期、保持不持股；2：今天刚卖出；3：今天处于冷冻期（昨天卖出）。今天买入只能从昨天的 1 或 3 转入，不能从昨天的 2 转入。

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:

            return 0

        for i in range(1, len(prices)):
```

```python
            return 0
```

## 41. 最长递增子序列

### 41.1 最长递增子序列：二维枚举、一维状态

原代码 / 片段：PDF 第 181-183 页。

dp[i] 表示必须以 nums[i] 结尾的最长严格递增子序列长度；答案需要在所有结尾里取最大值。

```python
class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        if len(nums) <= 1:
            return len(nums)
        dp = [1] * len(nums)  # 单个元素也构成长度为 1 的子序列。
        result = 1
        for i in range(1, len(nums)):
            for j in range(i):
                if nums[i] > nums[j]:  # 严格递增，不允许相等。
                    dp[i] = max(dp[i], dp[j] + 1)
            result = max(result, dp[i])
        return result
```

### 43.1 版本一：带空前缀的二维 DP

### 43.2 版本二：一维滚动数组

### 43.3 版本三：直接以 i、j 为结尾，手动初始化边界

原代码 / 片段：PDF 第 191 页。

```python
    def findLength(self, nums1: list[int], nums2: list[int]) -> int:

            return 0
        n, m = len(nums1), len(nums2)
        dp = [[0] * m for _ in range(n)]
        for i in range(n):
            if nums1[i] == nums2[0]:
                dp[i][0] = 1
        for j in range(m):
            if nums1[0] == nums2[j]:
                dp[0][j] = 1

        result = 0
        # 从 0 开始扫描，第一行、第一列的答案也必须被收集。

            for j in range(m):
                if i > 0 and j > 0 and nums1[i] == nums2[j]:

        return result
```

## 52. 回文子串

### 52.1 版本一：动态规划，展开分类讨论

原代码 / 片段：PDF 第 221-223 页。

dp[i][j] 表示闭区间 s[i:j+1] 是否为回文。依赖内部区间 dp[i+1][j-1]，所以 i 从右向左，j 从 i 向右。

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        dp = [[False] * n for _ in range(n)]
        result = 0
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j]:
                    if j - i <= 1:
                        # 长度 1 或 2：首尾相同就一定是回文。
                        dp[i][j] = True
                        result += 1
                    elif dp[i + 1][j - 1]:
                        # 长度大于 2：首尾相同，内部也必须是回文。
                        dp[i][j] = True
                        result += 1
        return result
```

时间：O(n²)；空间：O(n²)。

```python
        result = 0
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j - i <= 1 or dp[i + 1][j - 1]):
                    dp[i][j] = True
                    result += 1  # 每个不同起止位置的回文区间各算一次。
        return result
```

时间：O(n²)；空间：O(n²)。


### 52.3 版本三：双指针中心扩展

原代码 / 片段：PDF 第 224-225 页。

分别枚举单字符中心和双字符中心，覆盖奇数长度、偶数长度的全部回文子串。

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        def extend(left, right):
            count = 0
            while left >= 0 and right < len(s) and s[left] == s[right]:
                count += 1  # 当前左右边界形成一个回文子串。
                left -= 1
                right += 1
            return count

        result = 0
        for i in range(len(s)):
            result += extend(i, i)      # 奇数长度，以一个字符为中心。
            result += extend(i, i + 1)  # 偶数长度，以两个字符之间为中心。
        return result
```

时间：O(n²)；空间：O(1)。

### 53.1 最长回文子序列：区间动态规划

原代码 / 片段：PDF 第 225-227 页。

dp[i][j] 表示 s 在闭区间 [i,j] 内最长回文子序列的长度。子序列允许跳过字符，因此首尾不等时取去掉任意一端后的最大值。

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        if not s:
            return 0
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = 1  # 任意单个字符都是长度为 1 的回文子序列。
        for i in range(n - 1, -1, -1):
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    # 相邻两个字符时，内部为空，预置的 0 正好适用。
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        return dp[0][n - 1]
```

时间：O(n²)；空间：O(n²)。
